# Gold AI Android

Mobile Android application for XAU/USD technical analysis.

## Build on GitHub from an Android phone
1. Create a new GitHub repository named `gold-ai-android`.
2. Upload the contents of this folder to the repository root.
3. Open **Actions** and select **Build Android APK**.
4. Run workflow.
5. When complete, open the workflow run and download the `GoldAI-debug-apk` artifact.
6. Extract the APK and install it on your Android phone.

This build is analysis-only and contains demo/reference market values. It does not place trades. Connect a legitimate live market-data API and validate the strategy before using real money.
